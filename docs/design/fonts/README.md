# Fonts for the design

Self-hosted font files for `../../DESIGN.md`. All three are under the SIL Open Font License 1.1, which allows redistribution. Keep each `LICENSE.txt` next to its files.

| Folder | Use | Source |
|---|---|---|
| `literata/` | Headings and body text | Literata, via fontsource |
| `ibm-plex-sans/` | The interface: navigation, buttons, labels, table headers | IBM Plex Sans, via fontsource |
| `jetbrains-mono/` | Optional: a code or an ID | JetBrains Mono, via fontsource |

Each folder has the Latin and Latin Extended files (the second covers the Polish letters ą ć ę ł ń ś ź ż), upright and italic, and a `meta.json` with the unicode ranges.
The files are copies of the team design library, checked by checksum on 3 October 2026.

**General Sans is not here on purpose.** Its licence (ITF Free Font License 2.0) forbids distributing the files through a repository.
